# Rimon Akhter — Portfolio Site

## Project
Single-page portfolio for a senior game/VR developer.
Stack: Pure HTML + CSS + Vanilla JS + Three.js (CDN). No React, no build tools.
One file: index.html

## Design System
- Theme: Cyberpunk Terminal
- Background: #080e0d (near-black green-tinted)
- Accent: #00ffcc (cyan)
- Muted: #3a6460, #5a8a84
- Text: #c8e8e4, #e8f8f5
- Heading font: Syne (800 weight) — Google Fonts
- Body/code font: Space Mono — Google Fonts
- No gradients, no rounded blobs, no purple/pink AI aesthetics
- Feels like a game dev HUD / terminal

## 3D / Animation
- Three.js via CDN for hero background (particle field, reactive to mouse)
- CSS transitions for scroll fade-ins and hover states
- Subtle, not distracting — performance first
